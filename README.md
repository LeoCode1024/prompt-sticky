# 提示词便签

当前版本：`1.1.0`

提示词便签是一个 Windows 本地桌面小工具，用来保存、管理和快速复制常用 AI 提示词。它适合经常和 ChatGPT、Codex、Claude、通义、Kimi 等 AI 工具对话的人：不用再打开 Excel 表格反复查找、复制、粘贴，只需要把鼠标移到桌面上的便签图标，就能展开一张轻量的提示词表格。

这个工具是绿色版程序，数据默认保存在当前 Windows 用户目录中，不上传、不联网，也不会把提示词写进 exe 文件。

## 功能亮点

- 桌面悬浮图标：平时只显示一个半透明便签图标，尽量不打扰桌面。
- 鼠标悬停展开：鼠标移动到图标上时自动展开为提示词表格，移开后延迟收起。
- 两列表格管理：固定为“类型”和“提示词”两列，适合按场景整理常用提示词。
- 快速复制：单击任意单元格即可复制内容，复制成功后显示 `√`。
- 直接编辑：双击单元格进入编辑；`Enter` 完成编辑，`Shift+Enter` 在单元格内换行。
- 多行提示词：支持保存和复制多段、多行文本。
- 行管理：可以新增行、删除当前行，删除前会弹窗确认。
- 锁定与解锁：解锁状态下可以拖动位置和调整大小；锁定状态下固定窗口。
- 置顶开关：可选择是否让图标始终显示在其它窗口上方。
- 开机自启动：可在工具内切换是否跟随系统启动。
- CSV 导入导出：同一个按钮内可选择导入或导出 CSV，支持追加或替换当前表格。
- 自动保存：录入内容会自动保存到当前设备，不需要手动保存。
- 简洁界面：浅黄色纸张风格背景，展开时带卷轴式动画。

## 适用场景

- 保存常用 AI 提示词，例如润色、总结、翻译、代码解释、写作提纲等。
- 保存不同工作流中的固定指令，例如“按表格输出”“先提问再回答”“用中文解释”等。
- 替代 Excel 或文本文档中的提示词清单，减少打开文件和复制粘贴的操作。
- 在只需要本地使用、不希望数据同步到云端的场景下管理提示词。

## 使用方式

1. 运行 `PromptSticky.exe`。
2. 在桌面找到半透明便签图标。
3. 鼠标移到图标上，工具会自动展开。
4. 单击单元格复制内容。
5. 双击单元格编辑内容。
6. 使用顶部图标按钮新增行、删除行、锁定窗口、切换置顶、导入或导出 CSV。
7. 鼠标移开后，工具会在短暂延迟后自动收起为图标。

顶部按钮均为图标显示，鼠标悬停在按钮上会显示对应功能说明。

## 数据保存位置

提示词数据保存在当前 Windows 用户目录：

```text
%AppData%\PromptStickyTool\settings.xml
```

异常日志会写入：

```text
%AppData%\PromptStickyTool\error.log
```

这些文件是本机用户数据，不建议提交到 GitHub 仓库。

## CSV 导入导出

CSV 文件建议使用两列：

```csv
类型,提示词
润色,请帮我润色下面这段文字，保持原意，语气自然。
总结,请用要点总结以下内容，并给出下一步建议。
```

导入 CSV 时可以选择：

- 追加：把 CSV 内容添加到现有表格后面。
- 替换：清空当前表格后使用 CSV 内容。
- 取消：不执行导入。

导出的 CSV 使用 UTF-8 编码，并支持提示词中的逗号、引号和多行文本。

## 构建方式

本项目使用 C# WPF 编写，通过 Windows 自带的 .NET Framework 编译器构建，不需要安装完整 Visual Studio。

在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建完成后会生成：

```text
dist\PromptSticky.exe
```

## 隐私说明

提示词便签是本地工具：

- 不需要登录账号。
- 不连接服务器。
- 不上传提示词。
- 不内置云同步。
- 提示词数据只保存在当前 Windows 用户目录中。
